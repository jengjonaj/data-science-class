# Data Science Class

My notebooks, practice exercises, and notes for **MECE 4520: Data Science for Mechanical Systems — Fall 2026**.

## Topics covered

- Python basics, NumPy, and Pandas
- Selecting, filtering, and summarizing data
- Creating plots with Matplotlib
- Exploratory data analysis (EDA)
- Checking missing values and potential outliers
- Understanding distributions, correlations, and causation

## Course dataset

The foundations exercises use gas-turbine measurements to explore operating conditions and CO and NOx emissions. The course version includes a `campaign_year` column and missing values for practice.

## Using the notebooks

Open `.ipynb` files on GitHub to view code, notes, and saved results. To run or edit them, open them in Google Colab and run the cells from top to bottom.
